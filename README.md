# Mochi 字卡传讯

一个纯本地运行的单人互动字卡应用。数据保存在浏览器本地（IndexedDB），不上传任何服务器。

## 部署

这是纯静态站点，可直接用 GitHub Pages 托管：
- 进入仓库 **Settings → Pages**
- Source 选择 **Deploy from a branch** → 分支选 `main` → 目录选 `/ (root)`
- 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 说明

- 无需构建、无依赖，直接用浏览器打开 `index.html` 即可运行
- 数据存在各自设备的浏览器本地，换设备请用应用内「设置 → 通用 → 导出/导入」迁移
- 本版本已删除开屏公告，并修复了「发消息后 TA 回复未生成就被后台杀掉、重开补发」的问题
